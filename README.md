# Portofolio

Website portofolio pribadi yang dibuat menggunakan HTML, CSS, dan JavaScript.

## Deskripsi

Website ini dibuat sebagai project pembelajaran web development.
Website menampilkan informasi mengenai diri, kemampuan, dan project
yang telah dibuat.

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript

## Fitur

- Halaman Home
- Halaman About
- Daftar Skill
- Daftar Project
